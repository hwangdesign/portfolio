# 이력서 (Resume)

정적 사이트 루트(`index.html`)의 **RESUME** 버튼은 `resume/index.html`을 가리킵니다.

Next.js 앱(`app/`)은 `public/resume/`에 동일한 파일을 두고 `/resume/index.html`로 제공합니다. 내용을 수정할 때는 **두 디렉터리를 동일하게 맞추세요.**

| 용도 | 경로 |
|------|------|
| GitHub Pages 등 정적 배포 | `resume/` |
| Next.js `public` | `public/resume/` |

이전 별도 저장소 `resume`는 이 폴더로 통합되었습니다. 원격 저장소는 아카이브하거나 삭제해도 됩니다.
