Trending Searches

+ Google Trends와 네이버쇼핑 인기 검색어를 종합한 쇼핑 키워드 랭킹이에요.

+ Puppeteer 크롤링·GitHub Actions로 매일 자동 수집해요.

SITE

Google Trends · 네이버쇼핑 — Google Trends 쇼핑 카테고리, 네이버 쇼핑인사이트를 참고해 Puppeteer로 인기 검색어를 수집해요. 두 소스를 종합해 점수(101-순위)를 합산하고, 양쪽 모두에 등장한 키워드가 상위에 노출돼요.

JSON & 뷰어 — google_trends_M-D-YYYY.json, naver_shopping_M-D-YYYY.json 형식으로 저장하고, fetch로 불러와 탭 전환(종합 랭킹 / Google Trends / 네이버쇼핑)으로 보여줘요. 키워드 클릭 시 검색 페이지로 연결돼요. npm run collect로 로컬 수집·테스트가 가능해요.
